# Team-Page

A multi-page responsive website built using **HTML, CSS, and JavaScript**, featuring dedicated pages for team information, news, FAQs, blogs, services, events, resources, careers, partners, testimonials, galleries, contact information, and more.

The project demonstrates practical frontend development concepts including reusable styling, interactive JavaScript functionality, responsive page design, navigation, UI components, and theme customization.

## ✨ Features

- 🏠 Home page with structured website navigation
- 👥 Team and organization information
- 📰 News and updates section
- ❓ Interactive FAQ pages
- 📝 Blog and article pages
- 🤝 Partners and collaboration section
- 💼 Careers and new-hire information
- 🛠️ Services and resources pages
- 📅 Events section
- 🖼️ Gallery page
- ⭐ Testimonials section
- 📍 Address and contact pages
- 🎨 Custom CSS styling and UI components
- 🌗 Theme/UI customization with JavaScript
- 📱 Responsive frontend layouts
- 🔗 Multi-page navigation
- 🚀 GitHub Pages-ready deployment

## 🚀 Getting Started

### Clone the repository

```
git clone https://github.com/divziv/Team-Page.git
```

### Navigate to the project

```
cd Team-Page
```

### Run locally

Since this is a static HTML/CSS/JavaScript project, no backend server or package installation is required.

You can open:

```
index.html
```

directly in a browser.

For a better development experience, you can also serve the project using a local development server such as VS Code Live Server.

## 🌐 Deployment

The project can be deployed as a static website using **GitHub Pages**.

Once GitHub Pages is enabled for the repository, the static HTML, CSS, and JavaScript files can be served directly without requiring a backend application.
